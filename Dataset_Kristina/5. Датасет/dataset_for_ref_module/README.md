# Размеченный корпус текстов

Каждый текст в dataset.json находится отдельно в фигурных скобках. Они не отделены друг от друга запятыми, что может привести к ошибкам в время парсинга. Для этого необходимо либо предварительно их проставить, либо разделить на разные файлы.

Номер текста из папки texts указан в external_id. Пример:
```
"data_row": {
    <...>
    "external_id": "text_542718.txt",
}
```

Для каждого термина указаны разнообразные данные. Название класса термина указано в name, а его расположение в тексте location (считается по символам). Пример:
```
"projects": {
    "some_hash_name": {
        "labels": {
            "annotations" : {
                "objects": [
                    {
                        "name": "Method",
                        "location": {
                            "start": 15,
                            "end": 17
                        }
                    },
                    <...>
                ]
            }
        }
        
    }
}
```
