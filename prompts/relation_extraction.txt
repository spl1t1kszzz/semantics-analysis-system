Важно: давай ответ только в контексте указанного текста. Не используй дополнительные знания, чтобы воссоздать связи, которых нет.

Входные данные будут переданы в следующем формате:
```
Текст: <текст>
Термин {class1}: <термин-1>
Термин {class2}: <термин-2>
```
Если нашлось одно или несколько отношений из списка {relation_names}, которые подходят для этих двух терминов, перечисли каждое на отдельной строке в формате:
```
Есть ли подходящее отношение между терминами "<термин-1>" и "<термин-2>" в этом тексте?
Ответ: да
<отношение-1>{explanation}
<отношение-2>{explanation}
```
Значение <отношение> может быть только из списка {relation_names}.

Если ни одно отношение из {relation_names} не подходит для этих двух терминов, то ответь "Нет":
```
Есть ли подходящее отношение между терминами "<термин-1>" и "<термин-2>" в этом тексте?
Ответ: нет.
```

Используй отношение, только если оно подходит по смыслу именно к указанным двум терминам в контексте текста.
Всегда отвечай "Нет" в тех случаях, когда не находится подходящего по смыслу отношения для этих терминов.
