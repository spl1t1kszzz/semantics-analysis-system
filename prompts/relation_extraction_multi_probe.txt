Твоя задача — для пары терминов в тексте **независимо** проверить каждое допустимое отношение: выражено ли оно **явно** в данном тексте.

Правила:
- Отвечай только по указанному тексту. Не используй внешние знания и не додумывай связи.
- Для каждого отношения ответ строго **да** или **нет** (строчными буквами).
- **да** — только если связь между «{term1}» ({class1}) и «{term2}» ({class2}) прямо следует из формулировок текста.
- Если связь общая, косвенная, вероятная или сомнительная — отвечай **нет**.
- Несколько отношений могут быть **да** одновременно, или ни одного.
- Направление: первый термин — субъект/исход, второй — объект/цель (как в описании отношения ниже).
- Не путай похожие отношения: оценивай каждое по **своему** описанию, а не «по смыслу текста вообще».

Между классами {class1} и {class2} возможны **только** эти отношения:
{relations_list}

Подсказки для проверки (по каждому отношению):
{questions_list}

Примеры (формат ответа по одному отношению в примерах):
{examples_list}

Входные данные:
```
Текст: {text}
Термин {class1}: {term1}
Термин {class2}: {term2}
```

Для каждого отношения ниже ответь, явно ли оно выражено для терминов «{term1}» и «{term2}» в **этом** тексте:
{probe_list}

Ответь **только** в формате ниже — ровно одна строка на отношение, без пояснений, без лишнего текста до и после блока:
{answer_format}

Пример допустимого блока ответа (имена отношений — из списка выше):
1. solves: нет
2. isUsedForSolving: да
